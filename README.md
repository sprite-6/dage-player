# 大哥的播放器

安卓端 NAS 音频播放器。直连家用 NAS 的 SMB 共享，把里面的儿童故事/读物按文件夹列出来播放，不转存、不上传。

- 包名：`com.dage.player`　版本：1.9.4　支持 Android 8.0+（minSdk 26，targetSdk 34）
- 安装包：见 [Releases](../../releases) 页下载最新 APK

## 目录结构

仓库里只有源码和资源。下面这些是本地开发用的目录，**不随仓库分发**（已在 `.gitignore` 中排除）：

## 功能

| 功能 | 说明 |
| --- | --- |
| 主界面显示文件夹 | 共享目录下的子文件夹以卡片形式排在首页，点进去是子文件夹 + 音频列表 |
| 点音频直接进播放页 | 列表里点任意一集，立刻切到全屏播放页（返回即回到列表） |
| 顶置/收藏文件夹 | 卡片/横条右侧的 ☆ 点一下即顶置，首页顶部单独成「顶置」区；在文件夹页面右上角 ☆ 也能收藏，深层目录（如 儿童故事/小王子）同样可直接置顶到首页 |
| 主题封面 | 25 张内置插画（童话/动物/恐龙/科普/三国/西游/睡前/英语/数学/音乐/安全…），按文件夹名关键词自动匹配，未命中回落渐变色块；全部本地资源，共约 580KB，不联网。可在设置里整体关闭 |
| 自定义封面 | 进任意文件夹 → 右上角图片按钮 → 从系统相册选一张，自动裁方压到 512px 存本地；也可「恢复默认」。手动指定的封面优先级最高，不受主题封面开关影响 |
| AI 封面（可选） | 用自己的 API Key（默认接 Agnes `agnes-image-2.5-flash`），按「文件夹名 + 前几集标题」生成封面。接口协议首次自动识别（三选一），之后固定；**增量生成**（只补没有封面的文件夹）；串行排队、请求间隔可配、429 自动退避，结果缓存本地；没配 key 就完全不联网 |
| 播放页封面回落 | 音频在子目录、封面生成在父目录时，播放页会逐层向上找（当前目录封面 → 当前目录主题插画 → 上层封面 → 宽松匹配），最多上溯 3 层，不越过媒体根目录 |
| 播放页封面 | 正在播放的专辑若已有手动/AI/内置封面，播放页原本的音乐图标会换成这张封面 |
| 搜索文件夹 | 首页右上角放大镜，输入即时过滤首页这一层的文件夹名，点结果直接进目录；只查内存里的列表，不发 SMB 请求 |
| 免责条款 | 设置 → 关于与免责条款，含软件性质、数据风险、凭据保管、AI 内容与第三方费用、责任限制等 |
| 两种展示方式 | 「大方块」两列卡片 / 「横条列表」紧凑行，右上角图标一键切换，设置里也能选，选择会记住 |
| 断点续播 | 每个文件单独记播放位置，首页有「继续收听」卡片，列表里未听完的显示进度条 |
| 后台播放 | Media3 MediaSessionService + 前台通知，锁屏、切后台、通知栏均可控制 |
| 自动下一集 | 同一文件夹内按自然序连播（第2集在第10集前面） |
| 睡眠定时 | 15/30/45/60/90 分钟，或「播完当前这集停止」，播放页显示剩余倒计时 |
| 双主题 | 跟随系统 / 浅色 / 深色，设置里切换，重启保持 |
| 格式 | mp3、m4a、m4b、aac、flac、wav、ogg、opus、mka（ExoPlayer 解码） |

## 首次使用

1. 手机与 NAS 连同一个 Wi-Fi（或同一局域网）。
2. 打开 App → 右上角齿轮 → 填：
   - **服务器地址**：NAS 的 IP，如 `192.168.1.10`；改了端口就写 `192.168.1.10:445`
   - **共享文件夹**：SMB 共享名，不是完整路径。点「浏览」可以尝试列出服务器上的共享
   - **子目录（可选）**：点右侧「选择」可以在共享里逐级点选（左上角上下级切换），选中后自动填入相对路径；也可以手填，留空就是从共享根目录开始
   - **用户名/密码**：NAS 的 SMB 账号
3. 点「测试连接」，看到「连接成功：N 个文件夹」就点「保存」。
4. 回首页刷新即可看到文件夹。

## 主题封面怎么工作

首页卡片和列表缩略图用的插画，是按**文件夹名关键词**匹配的本地资源，不联网、不耗电：

- 规则在 `ui/Covers.kt` 的 `themes` 列表里，**顺序即优先级**。比如「睡前童话」会命中"睡前"而不是"童话"；「恐龙世界」命中恐龙而不是动物
- 泛指类目录（故事/绘本/读物/精选）统一用"书堆"那张兜底图，避免和具体书名撞同一张
- 都没命中就回落成渐变色块 + 文件夹图标
- 图上**不画文字**：中文在图像模型里基本都会糊，标题由 App 叠在底部黑色渐变蒙层上，任何图上都是白字
- 卡片显示时会做 1.14 倍裁切：画面更饱满，同时把图角的水印推出可视区

想加/换封面：把 512×512 的 webp 放进 `app/src/main/res/drawable-nodpi/`，在 `Covers.kt` 里加一条 `Theme(R.drawable.cover_xxx, listOf("关键词1", "关键词2"))` 即可，不用改界面代码。

**手动指定封面**（v1.4）：进文件夹 → 右上角图片按钮 →「选一张图」走系统图片选择器（Photo Picker，不需要存储权限）→ 自动居中裁方、缩到 512×512、JPEG 88 存进 `filesDir/covers/<md5(文件夹URL)>.jpg`。取消用同一个菜单里的「恢复默认」。设置里可查看已设置数量并一键清空。

封面优先级：**手动指定 > 内置主题图（开关开启时） > 渐变色块**。所以关掉「主题封面」总开关时，手动设置的封面仍然保留。

> 关于"用 AI 按内容实时生成封面"：DeepSeek 的 API 只出文本（到 2026-10 仍无图像生成），要实时出图得再接一家图像模型（硅基流动/智谱/火山等），每张几分到几毛、首屏还要等生成。所以 v1.3 先用内置包保证"装上就有图、离线也能看"，实时生成作为后续可选项。

## AI 封面怎么配（v1.5，BYOK）

设置 → AI 封面，填四项就能用：

| 字段 | 默认值 / 说明 |
| --- | --- |
| Base URL | `https://api.agnes-ai.cn/v1`（国内节点；国际站是 `https://apihub.agnes-ai.com/v1`；任何 OpenAI 兼容的 `/images/generations` 都行） |
| 图像模型 ID | `agnes-image-2.5-flash`（**必须带 `image`**；`agnes-2.5-flash` 是对话模型，会报 400）。自己做界面不提供预设，四个字段手填即可 |
| API Key | 自己申请，只存本机（Android Keystore AES‑GCM 加密），可随时清空 |
| 尺寸档 / 比例 | `1K` + `1:1`；换成别家可以填像素值，程序会自己换算 |

**接口形态自动识别（v1.6）**：各家写法只在三处不同——尺寸是像素还是 `1K` 档位、比例放哪个字段、`response_format` 放顶层还是 `extra_body`。所以设置页有「测试接口」按钮，点一次会依次试三种形态：

```
① OpenAI 标准   size=1024x1024 + response_format=b64_json（顶层）
② Agnes 形态    size=1K + ratio + extra_body.response_format=url
③ 精简模式      只给 model/prompt/size，其余不传
```

第一个成功的形态会被记下来（`Prefs.aiProfile`），之后所有生成只走这一种，**不再试错、不重复消耗额度**。改了 Base URL / 模型 / 尺寸会自动作废，需要重新测试。

**提示词怎么用文件夹内容（v1.9.1）**：批量生成（补齐 / 全部重画）和单个生成现在都会先读目录，取**前 8 个标题**参与提示词。规则：

1. 文件夹页生成时如果填了「画面描述」，就**只按这句画**，忽略文件名（适合新闻、合集这类主题杂的目录）
2. 没填描述 → 把前 8 个标题交给模型，并要求它**先归纳共同主题再画**，不要照搬某一集
3. 目录名命中 `新闻/时事/播报/资讯/快讯/日报/晚报/朝闻/要闻/时政/财经` → 自动换成资讯类画风（简洁稳重、蓝灰藏青、避免卡通化）
4. 这一层只有子文件夹（如 `儿童故事/小王子/xx.mp3`）→ 自动往下找最多 2 个子目录取标题
5. 批量时会显示「正在读取目录内容 3/10」的进度条，读完才开始生成

**增量生成（v1.7）**：批量生成只处理"还没有封面"的文件夹——已经有的（不论是 AI 生成还是手动设的）一律跳过。

- 按钮会显示缺几个：「补齐缺失封面（3）」，都齐了变成「封面都齐了」并禁用
- 上方统计：`共 9 个文件夹 · 已有封面 6 个 · 缺 3 个`
- 新增文件夹后回这一页，数字会自动刷新，点一下只补新的
- 想推倒重画：点「全部重新生成」，会二次确认并提示会覆盖已有封面、每个都消耗额度

**为什么这样设计限流**：免费额度通常有"每分钟几次"的限制，所以：并发固定为 1、两次请求强制间隔（默认 12 秒，最小 3 秒）、遇到 429 等 60 秒重试最多 2 次、401/402/429/400 分别给不同提示。没有做"每日上限"，额度用完与否由服务端自己报错。

**错误提示（v1.8）**：识别出模型名填成了对话模型时，直接告诉你该改成哪个名字，并且不再换着形态重试（原本会白试 3 次）；Base URL 是 Agnes 域名但模型名不含 `image` 时，输入框下方会提前给出警告。

**安全边界**：Key 用 Keystore 加密后存 prefs，`allowBackup=false` 且 `dataExtractionRules` 禁止云备份/换机迁移带走；APK 里不含任何 Key；只发送文件夹名和文件名，不发送音频。设备被 root 仍可能读到，条款里已写明。

> 注意：本项目只在**本地假接口**上跑通过完整链路（请求构造、三形态协商、增量判定、解析、裁剪、缓存、刷新），尚未用真实 Agnes Key 验证最终出图质量与限流阈值，首次使用请先点「测试接口」再单个生成一张。

## 技术实现

- Kotlin + Jetpack Compose（Material 3），单 Activity + Compose Navigation
- 播放：Media3 ExoPlayer 1.4.1，`MediaSessionService` 承载后台播放与通知
- SMB：jcifs-ng 2.1.10（含 BouncyCastle），按 SMB3.0.2 → SMB2.1 → SMB1 顺序协商，取第一个可用的
- 流式播放：自定义 `SmbDataSource`（基于 `SmbRandomAccessFile`），支持按字节 seek，所以进度条可拖动，不整文件下载
- 状态：SharedPreferences（配置/主题/断点），进程被杀后仍在
- 排序：自然排序比较器，数字段按数值比较

## 已知边界

- WMA / APE 没有解码器，列表里不显示。
- 文件名里如果带 `#`、`?` 这类 URL 保留字符，可能读不出来（SMB URL 解析限制）。
- 睡眠定时是进程内状态，App 被系统杀掉后需要重设。
- 「浏览共享」依赖服务器的共享枚举，部分 NAS 关闭了该功能时会失败，此时手动填共享名即可。
- 局域网内明文 SMB，建议只在家里 Wi-Fi 用，不要把 445 端口映射到公网。

## 重新编译

```bash
export JAVA_HOME=~/jdk/jdk-17.0.21+9/Contents/Home
export ANDROID_HOME=~/Library/Android/sdk
./gradlew :app:assembleRelease
```

签名信息**不进版本库**：在 `local.properties` 里配置（该文件已被 `.gitignore` 排除），或用环境变量：

```properties
RELEASE_STORE_FILE=app/dage.jks
RELEASE_STORE_PASSWORD=你的密码
RELEASE_KEY_ALIAS=你的别名
RELEASE_KEY_PASSWORD=你的密码
```

没配这几项时，`assembleRelease` 仍能出包，只是不做签名。自己 fork 后请用 `keytool` 生成自己的密钥，不要复用别人的。
